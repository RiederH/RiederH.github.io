# Rieder Gupta’s Portfolio

Public website: https://riederh.github.io/

This repository contains the portfolio website only. Atlas, Workflow, GuptaLink, and coursework implementations are not included.

## Private project repositories

- [Project Atlas + Widgets](https://github.com/RiederH/Project-Atlas)
- [Project Workflow](https://github.com/RiederH/Project-Workflow)
- [GuptaLink A.I](https://github.com/RiederH/GuptaLink-R.A.G.-Platform)

These are links only. They do not grant access to private repositories, and the website does not fetch their contents. No submodules, access tokens, or private-source build steps are needed.

## Update the website

Edit the HTML, CSS, JavaScript, and project descriptions in this repository and push to main. GitHub Pages publishes from the root of main. The `.nojekyll` file keeps this a plain static site. Test the public URL after changes.

Keep project implementations, personal data, and secrets in their separate private repositories. Changes made in those repositories do not automatically update this showcase.
